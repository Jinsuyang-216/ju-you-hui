🛡 聚优惠 · 三层爬虫工具策略

主选浏览器直连，两路本地 CLI 备用，覆盖反爬 / 验证码 / 登录态优惠

① 主选 · Firecrawl

云端 REST API，浏览器直连，无需本地环境。抓 smzdm 等公开优惠页，双击本页点「搜优惠」即用。免登录、自动处理反爬。

② 备用 · BrowserAct

本地 CLI browser-act，stealth-extract 零配置突破反爬、solve-captcha 自动解验证码。适合美团/抖音等被拦截的优惠页，免费(登录)。

③ 备用 · OpenCLI

本地 CLI opencli + Chrome「Browser Bridge」插件，复用浏览器登录态，覆盖京东/美团等需登录的全量优惠库。

用法：主选直接点「📍选地区 → 搜优惠」即可联网抓取；两个备用工具需在本机终端跑 CLI 抓数据，导出 JSON 后点「📤 导入」即可进入聚优惠统一管理。

备用② BrowserAct（本地 CLI）

# 1. 安装 CLI（详见 https://github.com/browser-act/skills） npm install -g browser-act # 2. 登录（免费层需登录账号） browser-act login # 3. 零配置抓取受保护的优惠页（如美团/抖音 deal 页） browser-act stealth-extract "https://www.meituan.com/deal/..." --out ba_heka.json # 4. 多页抓取后合并，回到聚优惠点「📤 导入」选 ba_heka.json

备用③ OpenCLI（本地 CLI + Chrome 插件）

# 1. 安装 npm install -g @jackwener/opencli # 2. 安装 Chrome「Browser Bridge」插件并完成登录 # 3. 抓取优惠（聚优惠专用适配器，详见 clis/juyouhui/） opencli juyouhui search "成都 奶茶" -f json > juyouhui.json # 4. 回到聚优惠点「📤 导入」选 juyouhui.json

说明：BrowserAct / OpenCLI 均为本地命令行工具，无法在纯前端网页内直接调用，故作为「备用」，通过「CLI 抓取 → 导出 → 导入」与聚优惠衔接。主选 Firecrawl 才是网页内一键直连的方案。

浏览器出于安全限制，无法由网页按钮直接运行你电脑上的程序。两种方式任选其一：

下方已为你生成启动器内容。若浏览器允许下载，请到【下载】文件夹双击运行；若被系统拦截，改用方式一。
